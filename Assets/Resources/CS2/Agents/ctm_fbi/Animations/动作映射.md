# FBI 探员动画映射

Unity 里 clip 全名是：

`agents\models\ctm_fbi\ctm_fbi.vmdl_c|<短名>`

预览面板和下面表格用的都是 **短名**（`|` 后面那一段）。在 Project 窗口点开对应 FBX → Animation 列表即可找到。

| 资产 | 用途 |
|---|---|
| `ctm_fbi_tp_rifle_move.fbx` | 第三人称步枪走跑蹲跳、梯子、瞄准走 |
| `ctm_fbi_tp_pistol_move.fbx` | 第三人称手枪走跑蹲跳、梯子、瞄准走 |
| `ctm_fbi_ak47_p250.fbx` | AK47 / P250 掏枪、换弹、射击、检视（含第一人称） |
| `ctm_fbi_tp_knife_move.fbx` | 第三人称刀具走跑蹲跳、梯子、瞄准走 |
| `ctm_fbi_knife_butterfly.fbx` | 蝴蝶刀掏刀、待机、挥砍/背刺（含第一人称） |

- **AK47** 移动用步枪包，持枪动作用 `ak47_p250` 里带 `_ak` 的 clip。
- **P250** 移动用手枪包，持枪动作用 `ak47_p250` 里带 `_p250` 的 clip。
- **蝴蝶刀** 移动用刀具包，掏刀/挥砍/检视用 `knife_butterfly`。第三人称劈砍复用默认刀动作（蝴蝶刀没有独立 TP 挥砍）。
- CS2 没有第一人称走跑蹲，移动全是第三人称。

方向：`n` 前、`s` 后、`e` 右、`w` 左，`ne/nw/se/sw` 为斜向。FBX 名字有 31 字符截断，表里「短名」以 Unity 里实际为准。

## 跳跃 / 滞空 / 叠加

步枪包和手枪包各有一套。叠加（Additive）是叠在走跑上的起跳/落地，不是完整跳跃。

## 原地转向

站着/蹲着、左转/右转，角度 23° / 34° / 45°，以及 45°/90°/180° 循环。

步枪示例：`tp_turn_left_45_rifle`、`tp_turn_right_loop_90_r`、`tp_turn_left_23_crouch_`。  
手枪同结构，后缀变成 `_pisto` / `_crouc`（被截断）。

---

## 瞄准走（Planted）

腰射/开镜时脚在挪、上身相对稳住。`e2w` 表示从东转向西（右→左），`n2s` 前→后，以此类推。`slow` 慢、`walk` 走、`start` 起步、`crossleg` 交叉步。

步枪：`tp_planted_n2s_rifle`、`tp_planted_walk_e2w_rif`、`tp_planted_start_n_rifl`。  
手枪：`tp_planted_n2s_pistol`、`tp_planted_walk_e2w_p`。

---

## 梯子

`back` 背对梯子，`facing` 面对梯子。`fast` 快速爬，`crouch` 蹲爬。数字是朝向角度。同名过多时 Unity 会加 `.001` `.002`。

步枪：`tp_ladder_facing_fast_r`、`tp_ladder_back_crouch_n`。  
手枪：`tp_ladder_facing_fast`、`tp_ladder_back_crouch`。

---

## 没进现有包的动作

死亡、受击 flinch、闪白、拆弹、人质、购买菜单，当时故意没导。其它刀具皮肤（刺刀、鲍伊等）只有独立掏刀/待机，挥砍仍用默认刀。
