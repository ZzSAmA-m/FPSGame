ctm_fbi 骨骼手册

预制件 Player_Net 下的 CS2 FBI 骨架。Animator 驱动的是子物体 ctm_fbi。这是 Generic 骨架，AvatarMask 只能按 Transform 路径勾选。

Unity AvatarMask：勾选 = 这层动画驱动这根骨； 取消勾选 = 遮住，这层不管它。

先看这个

做第三人称时建议两层叠：Base 只管腿，Upper 只管胸以上和枪。 换弹、死亡再用 Override 盖上去。配件骨（jiggle）和手臂扭转骨（TWIST）默认遮住： jiggle 跟着身体走即可；TWIST 由 FbiAnimator 脚本写。 thirdperson_body 这类是网格，不是骨头，Mask 里全部遮住，用 Renderer 开关。

分动作要勾哪些名字

1. 第三人称移动（Base 层）

勾选

  • root_motion（用 Root Motion 时）
  • pelvis
  • 左腿：leg_upper_L → leg_lower_L → ankle_L → ball_L
  • 右腿：同样一套 _R
  • 腿扭转：leg_upper_L/R_TWIST、TWIST1

取消勾选

  • 从 spine_1 往上整棵（胸、头、双臂、手指）
  • 全部 jiggle_*
  • scap_AIMUP、scap_*_AIMAT
  • wpnPivot、wpn
  • 所有网格物体

现有 MaskLeg.mask 只勾了两条大腿，小腿和脚是关的，不能直接用。把 pelvis 到 ball 整条勾上。

2. 上半身瞄准 / 持枪（Upper 层）

勾选

  • spine_1 spine_2 spine_3
  • neck_0 head_0
  • 左右：clavicle scapula arm_upper arm_lower hand
  • 全部手指
  • scap_AIMUP scap_L_AIMAT scap_R_AIMAT
  • wpnPivot wpn

取消勾选

  • root_motion pelvis 和整条腿
  • 手臂 TWIST / TWIST1（脚本写）
  • 全部 jiggle、眼球、网格

3. 第一人称 fp_*

勾选

  • clavicle_L/R 起的双臂、双手、全部手指
  • 需要时加 spine_3
  • 武器跟骨架走则勾 wpnPivot/wpn

取消勾选

  • 骨盆、腿、头、腰（spine_0/1）
  • jiggle、AIM 辅助、第三人称网格

本地玩家打开 firstperson_* 网格，关掉 thirdperson_*。别人看到的 Player_Net 反过来。

建议最少做的 3 张 Mask

  1. Mask_Legs：pelvis + 双腿到脚 + 腿 TWIST。
  2. Mask_UpperAim：spine_1~3 + 头颈 + 双臂手指 + 锁骨肩胛 + AIM + wpn。手臂 TWIST 不勾。
  3. Mask_FPArms：锁骨到手指（+ wpn）。腿头腰全关。

换弹用 Upper 或单独 Override；死亡用变形骨全勾、网格仍关。
