# TP 多骨骼俯仰

`PlayerAimPoseController` 只处理 TP 状态。角色保持当前共用骨架结构；切换前通过 `OnViewChanging` 撤销 TP 覆盖，再由原有模型组件切换视角。FP 状态不采样骨骼、不求解 IK，也不写入骨骼、相机或模型挂点。

角度来自 `PlayerSightController.AppliedPitch`，因此服务器、本地预测和远端快照插值使用同一个已提交的显示角度。表现组件不积分输入、不推进枪械，也不参与移动回滚重放。

## 姿态与配置

在 Player Prefab 的组件中配置 TP 根、角色 Animator、四段脊柱、颈头、左右上臂/前臂/手与 `wpn`。这些引用必须属于当前 TP 模型。使用角色的世界右轴施加俯仰，不把导入骨架的局部 X 当作俯仰轴。

默认躯干角度为 `Clamp(pitch * 0.65, -35, 50)`。四段脊柱分配为 10%、20%、30%、40%；剩余视线角度由颈部承担 60%、头部承担 40%，限幅分别为 ±35°、±25°。正角度低头，负角度抬头。

每帧先恢复上帧保存的动画姿态，Animator 求值后再叠加本帧修正。不使用绑定姿态覆盖动画，不修改动画速度、播放时间、骨长或缩放。

## 枪械与动作

持握、开火时，枪和双手接受同一组俯仰目标，再共同求解双臂 IK。瞄准是在本帧原动画上叠加视角俯仰，保留原动画的后坐、手腕朝向及肘部动作，不表示消除所有动画枪口偏移。

准备、换弹期间保留原动作关系，瞄准约束以 0.1 秒过渡退出；准备或换弹完成后重新过渡进入。刀具只应用身体、颈头俯仰和挂点随动。不同枪械沿用当前帧的动画姿态，无需增加固定握把资源或具体枪种分支。

目标不可达时优先共同平移枪与双手，保持朝向和骨长。双臂全部求解成功后才提交；无法满足约束时保留完整的身体叠加姿态，并给出一次诊断，避免残留半边 IK。

## 验证命令

通过 Unity Pipeline 执行 `player_aim_pose_setup` 配置真实 Player Prefab，执行 `player_aim_pose_validate` 检查真实骨架、动画、极限角度与 FP 隔离。联机数据和回归结果记录在 `Logs/TPAimValidation`。
