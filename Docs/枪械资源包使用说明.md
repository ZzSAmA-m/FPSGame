# 枪械资源包

每个 `GunSO` 引用一个 `GunResourcePackSO`。资源包只保存共享数据，不保存玩家、弹药、动画进度、随机状态或播放句柄。

## 配置入口

枪械 Inspector 的“资源配置”中设置资源包。枪械模型只以资源包中的 `ModelPrefab` 为准；旧 `WeaponSO` 模型字段继续供刀等非枪械装备使用。

模型应为完整的可装备预制体，根节点挂 `GunModelController`，子模型保留自身握持偏移。模型 Animator 必须放在能正确解析模型动画骨骼路径的位置。

资源包分别配置第一人称角色、第三人称角色、枪模型三组动作：

| 动作 | 触发方式 |
| --- | --- |
| Prepare | 枪械成功进入准备状态 |
| Hold | 准备或换弹结束、取消动作及视角/装备变化后恢复持握 |
| Fire | 每次成功射击并扣弹 |
| Reload | 枪械成功开始换弹 |

名称是 Animator 状态名，可填写完整层路径，例如 `FP Layer.fp_shoot1_ak`。它不是 Clip 文件路径。接入另一把枪时，需要在目标 AnimatorController 中建立对应状态并填写资源包，不需要修改播放组件中的枪种分支。

角色使用现有 FP Layer（2）和 Up Layer（1）；枪模型使用自身 Animator 的第 0 层。可选动作留空时不播放；配置的状态不存在时只给出一次诊断，不会改播 AK47 动画。

## 资源读取

`WeaponEntry.PresentationResources` 与 `PlayerHolder.CurrentPresentationResources` 提供 `IWeaponPresentationResources`：

```csharp
IWeaponPresentationResources resources = holder.CurrentPresentationResources;
if (resources != null && resources.TryGetAnimation(
        WeaponPresentationAction.Fire,
        WeaponAnimationTarget.FirstPerson,
        out string stateName))
{
    // 动画组件根据当前视角和对应层播放 stateName。
}

IReadOnlyList<AudioClip> clips = resources?.GetAudioClips(WeaponPresentationAction.Fire);
```

模型通过 `WeaponController.Bind(holder, entry)` 获取完整绑定上下文。绑定发生在 Holder 切换当前装备之前，因此模型应读取自己的 `Entry` / `PresentationResources`，不能在绑定时反查 Holder 的当前旧装备。

`Gun` 和 `GunConfig` 继续只保存枪械逻辑，不持有 Unity 模型或动画音频资源。

## 播放边界

本地预测和服务器权威枪械都转发生命周期事实：本地播放 FP，服务器角色播放 TP，模型根据同一行为播放自己的动画。玩家输入继续由 `PlayerBrain` 统一分发；运动回滚不执行枪械和表现链。自己的网络确认不重播本地动画。

动画保持素材原速。准备和换弹会在逻辑完成或取消时恢复持握，因此素材长于 GunSO 的 Tick 配置时可能被截断；本轮不自动修改逻辑 Tick，也不缩放动画速度。开火动画按自身播放结束恢复持握，持续成功射击可以重新触发。

当前 AK47 沿用拔枪末帧作为角色持握姿态、开火末帧作为模型持握姿态。切枪会取消旧动作并退订旧枪，不让旧事件影响新装备。

AK47 的原始 `TPAnims/tp_shoot_ak.anim` 是后坐力增量，不能直接放入 Override 层：其中骨段位置接近零，会把角色骨骼挤到一起。`Up Layer.tp_shoot_ak` 使用的是 `PresentationAnims/tp_shoot_ak.anim`，由 `GunRecoilClipBaker` 将原素材相对首帧的变化烘焙到 `tp_draw_ak` 末帧，保留原来的 0.75 秒、24 fps 和播放速度。原素材保留不变。重新迁移会自动重建；只修复该动画可执行 Pipeline 命令 `gun_tp_fire_repair`，验证使用 `gun_tp_fire_validate`。不要直接把整个 Up Layer 改为 Additive，因为准备和换弹仍是完整姿势。

## 音频只存资源

准备、开火变体和换弹音频直接引用 `AudioClip`，接口只返回引用。换弹音频列表是素材集合，不定义播放顺序或时间点。

玩家预制体上的 `PlayerFireAudioTester` 已移除。本轮没有新增音效加载、随机选择、分段调度或播放模块；配置音频引用不会自动发声。

本轮没有接入远端客户端的装备与动作表现同步，也没有修改网络消息或协议。
